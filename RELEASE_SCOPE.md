# SkillUp v1.0 — NEET Release Scope

## Official first release

SkillUp v1.0 is scoped to the **NEET syllabus**.

### Subjects
1. Physics
2. Chemistry
3. Biology

### Student flow
**Syllabus → Chapter → Concept → Learn → Practice → Mastery Test → Result → Review**

### Quality gate
Every published MCQ must contain:

**Question → 4 valid options → verified correct answer → specific explanation → tested concept**

Explanations must explain the actual biological, chemical, or physical reason for the answer. Generic statements such as “the concept supports this option” are not acceptable.

### Release rule
Do not mark a chapter complete merely because files exist. A chapter is release-ready only after content, answer keys, explanations, quiz behavior, navigation, and responsive presentation are verified.
