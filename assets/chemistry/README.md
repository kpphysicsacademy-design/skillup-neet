# SkillUp Chemistry Asset Library

Central media library for Chemistry questions.

## Types
- structures: reusable molecular/ionic structures
- reactions: reaction schemes and transformations
- diagrams: chemistry diagrams/charts
- mechanisms: reaction mechanisms

## Naming
Use permanent IDs in metadata, not filenames, as the stable reference.

Example:
CHEM-STR-000001 -> assets/chemistry/structures/benzene.svg

## Policy
Existing question-bank files remain untouched. New MCQs can reference assets by ID.
