Atoms, Molecules, Elements & Compounds

Four key ideas in one short visual sheet.

🎯 Start 30-question quiz

Atom

Basic unit of an element. Has protons, neutrons and electrons.

Molecule

Two or more atoms chemically bonded. Example: O₂, H₂O.

Element

Pure substance with one type of atom. Example: Fe, O₂, He.

Compound

Different elements chemically joined in a fixed ratio. Example: H₂O.

Quick comparison

Remember these

Atomicity: H₂ = 2, O₃ = 3, P₄ = 4 atoms.

Formula: H₂O = 2 H + 1 O; CO₂ = 1 C + 2 O.

H₂O molecular mass = 2(1) + 16 = 18 u

NaCl: ionic compound; represented by a formula unit, not a molecule.

Co ≠ CO: Co is cobalt; CO is carbon monoxide.
