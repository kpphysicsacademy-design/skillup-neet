Argument of a Complex Number

Understand the angle on the Argand plane, choose the correct quadrant, and practise with worked examples and a self-check quiz.

Learning objective

What is the argument?

For a non-zero complex number \(z=x+iy\), plot the point \((x,y)\) on the Argand plane. The argument is the angle \(\theta\) measured from the positive real axis to the line joining the origin to that point.

\[z=r(\cos\theta+i\sin\theta),\qquad r=|z|=\sqrt{x^2+y^2}\]

The argument is an angle, so it may be expressed in degrees or radians. Unless stated otherwise, this page uses the principal argument in the interval \((-\pi,\pi]\) (equivalently \((-180^\circ,180^\circ]\)).

How to find it

  1. Identify the real part \(x\) and imaginary part \(y\).
  2. Locate \((x,y)\) in the correct quadrant.
  3. Find the reference angle using \(\tan^{-1}(|y/x|)\), when \(x\ne0\).
  4. Adjust the angle for the quadrant and principal-argument convention.
\[\theta=\operatorname{atan2}(y,x)\]

Using atan2 is safer than using \(\tan^{-1}(y/x)\) alone because it accounts for the signs of both coordinates.

Quadrant guide

  • Quadrant I: \(x>0,y>0\), angle positive.
  • Quadrant II: \(x<0,y>0\), angle between \(90^\circ\) and \(180^\circ\).
  • Quadrant III: \(x<0,y<0\), principal angle negative.
  • Quadrant IV: \(x>0,y<0\), angle negative.

On the axes, use the axis angle directly. The argument of \(z=0\) is undefined.

Worked examples

Example 1: \(z=1+i\)

Point \((1,1)\) lies in Quadrant I. The reference angle is \(\tan^{-1}(1)=45^\circ\). Hence \(\arg(z)=45^\circ=\pi/4\).

Example 2: \(z=-1+i\)

Point \((-1,1)\) lies in Quadrant II. The reference angle is \(45^\circ\), so \(\arg(z)=180^\circ-45^\circ=135^\circ=3\pi/4\).

Example 3: \(z=-1-i\)

Point \((-1,-1)\) lies in Quadrant III. The geometric angle is \(225^\circ\), but the principal angle is \(-135^\circ=-3\pi/4\).

Example 4: \(z=3i\)

The point is on the positive imaginary axis, so \(\arg(3i)=90^\circ=\pi/2\).

Quick reference

\(1+i\) → \(\pi/4\)

\(-1+i\) → \(3\pi/4\)

\(-1-i\) → \(-3\pi/4\)

\(1-i\) → \(-\pi/4\)

\(i\) → \(\pi/2\)

\(-i\) → \(-\pi/2\)
