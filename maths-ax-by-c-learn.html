Equations of the Form ax + by = c

Brief Learn • Class 9 • Linear equations in two variables

📝 Practice Quiz📐 Simulate

1. What does ax + by = c mean?

It is a linear equation in two variables x and y. The letters a and b are coefficients, and c is a constant. For a genuine two-variable linear equation, a and b cannot both be zero.

ax + by = c
aCoefficient of x
bCoefficient of y
cConstant on the right side
x, yVariables whose values form solutions
Example: In 3x + 2y = 12, a = 3, b = 2 and c = 12. Standard form is 3x + 2y − 12 = 0.

2. What is a solution?

An ordered pair (x, y) is a solution when substituting both values makes the equation true.

For 2x + y = 7, the pair (3, 1) works because 2(3) + 1 = 7. The pair (2, 1) does not work because 2(2) + 1 = 5.

A linear equation in two variables has infinitely many real solutions. Each solution is a point on its graph.

3. Find intercepts

x-interceptPut y = 0, then solve for x.
y-interceptPut x = 0, then solve for y.
For 2x + 3y = 12:
Set y = 0 → 2x = 12 → x = 6, so (6, 0).
Set x = 0 → 3y = 12 → y = 4, so (0, 4).

4. Graph and special cases

The graph of a non-degenerate linear equation in two variables is a straight line. Two distinct solution points determine the line.

a = 0, b ≠ 0by = c → horizontal line.
b = 0, a ≠ 0ax = c → vertical line.
For 2x + 3y = 12, plot (6, 0) and (0, 4), then draw the straight line through them.

5. Quick method

  1. Identify a, b and c.
  2. Substitute an ordered pair to test it.
  3. To find x-intercept, set y = 0.
  4. To find y-intercept, set x = 0.
  5. Plot two solutions and join them with a straight line.
