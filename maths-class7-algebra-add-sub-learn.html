CLASS 7 · ALGEBRA

Add & Subtract Algebraic Expressions

Collect like terms. Add or subtract their coefficients. Keep unlike terms separate.

1. Add like terms

Like terms have the same variables with the same powers.

3x + 2x = (3 + 2)x = 5x

Add the coefficients and keep x unchanged.

2. Subtract like terms

7a − 4a = (7 − 4)a = 3a

Subtract the coefficients carefully, including their signs.

3. Group like terms first

2x + 3 + 4x

= 2x + 4x + 3 = 6x + 3

5a + 2b − 3a + b

= (5a − 3a) + (2b + b) = 2a + 3b

4. Subtract a bracket

A minus sign before brackets changes the sign of every term inside.

(5x + 3) − (2x + 1) = 5x + 3 − 2x − 1 = 3x + 2

Remember

• Arrange like terms together. • Add or subtract their coefficients. • Keep unlike terms separate. • Check every positive and negative sign.
