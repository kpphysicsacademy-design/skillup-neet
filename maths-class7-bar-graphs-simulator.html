Activity 01 · Build

Create your own bar graph

Enter matching categories and values to build a graph.

Create
Each bar represents one category. The number above each bar is its value.
Use up to 8 categories. Values must be non-negative whole numbers.
Activity 02 · Compare

Which category is greater?

Change the values and compare the largest, smallest and difference.

Compare
Difference = greatest value − smallest value.
Activity 03 · Scale

Read a bar graph scale

Find the value represented by a number of equal intervals.

Read
Bar value = number of intervals × value of each interval. For example, 6 intervals of 2 represent 12.
Activity 04 · Interpret

Read the data story

Use the values to find the total, average and range.

Analyse
Total = sum of values. Average = total ÷ number of categories. Range = largest − smallest.
