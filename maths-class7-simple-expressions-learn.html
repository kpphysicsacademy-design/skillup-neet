CLASS 7 · ALGEBRA

Simple Expressions

Learn how letters and numbers work together to represent quantities.

1. What is an algebraic expression?

An algebraic expression is made using numbers, variables and operations. It has no equals sign.

x + 5

This means “a number x increased by 5”.

2. Variables and constants

4a + 7

a is the variable. 4 is its coefficient. 7 is the constant.

A variable represents a number that may change. A constant has a fixed value.

3. Write words as expressions

5 more than x
x + 5
3 times n
3n
7 less than y
y − 7
Half of p
p ÷ 2

4. Like and unlike terms

Like terms have the same variables with the same powers. Unlike terms have different variable parts.

3x + 2x = 5x

But 3x + 2y cannot be combined.

5. Find the value

Replace the variable with the given number, then calculate.

If x = 4, then 2x + 3 = 2(4) + 3 = 11
