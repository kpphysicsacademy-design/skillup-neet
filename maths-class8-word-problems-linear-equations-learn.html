CLASS 8 • ALGEBRA

Word Problems Using Linear Equations

Turn everyday situations into equations. Choose a variable, express the relationships, solve, and check whether the answer makes sense in the original problem.

Read → Represent → Form an equation → Solve → Verify

1. Find the unknown

Read the problem and decide what quantity is unknown. Represent it with a variable such as x. Write down what each phrase means before forming the equation.

Example: A number increased by 7 is 19.
Let the number be x.
“Increased by 7” gives x + 7.
Equation: x + 7 = 19
x = 19 − 7 = 12.

2. Translate common phrases

A number increased by 5
x + 5
8 less than a number
x − 8
Three times a number
3x
One-fourth of a number
x/4
Two consecutive integers
x and x + 1
Two consecutive even integers
x and x + 2 (x even)

3. Money and quantities

Use the price or quantity of one item as the variable. Multiply by the number of items, then include any fixed cost or discount.

Example: Four notebooks and a ₹20 ruler cost ₹100.
Let one notebook cost ₹x.
4x + 20 = 100
4x = 80
x = ₹20.

4. Age problems

Represent a person's present age first. An age after n years is x + n; an age n years ago is x − n. Keep the same time reference for every person.

Example: A parent is three times a child's age. Their ages total 48 years.
Let the child's age be x; parent's age is 3x.
x + 3x = 48
4x = 48
x = 12 years.

5. Geometry and travel

Rectangle: Width = x, length = x + 3, perimeter = 30 cm.
2[x + (x + 3)] = 30
4x + 6 = 30, so x = 6 cm.
Taxi fare: Fixed charge ₹40 plus ₹12 per kilometre totals ₹100.
40 + 12x = 100
12x = 60, so x = 5 km.

6. A reliable solving method

  1. Read the whole problem and identify the unknown.
  2. Define the variable with units where needed.
  3. Translate each relationship into an expression.
  4. Form one equation using the condition in the problem.
  5. Solve using inverse operations and simplify carefully.
  6. Substitute the result into the original situation.
  7. State the answer with the correct unit and check that it is reasonable.

7. Common mistakes

Reversing a phrase
“5 less than x” is x − 5, not 5 − x.
Missing a fixed amount
Include fixed fees or extra costs in the equation.
Mixing time references
Compare everyone's ages at the same point in time.
Ignoring units
Write rupees, years, centimetres or kilometres in the final answer.

Quick revision

The variable represents the unknown quantity. Expressions represent the relationships. The condition creates the equation. Solve it, substitute the value back, and interpret the result in the original context.
