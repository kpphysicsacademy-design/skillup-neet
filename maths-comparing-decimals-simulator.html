Rules for Comparing Decimals

Use these steps whenever decimal numbers have different lengths.

1. Compare whole-number parts.
The number with the greater whole-number part is greater.
2. Compare tenths.
If whole-number parts match, compare the tenths digits.
3. Continue to the right.
Compare hundredths, then thousandths, until the first difference.
4. Use trailing zeros.
Write 0.6 as 0.60 to compare it easily with 0.58.
5. Equal values.
Different-looking decimals can have the same value, such as 1.2 and 1.20.
