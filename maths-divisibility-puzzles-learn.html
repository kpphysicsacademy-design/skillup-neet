Divisibility Puzzles

Brief Learn • Class 8 • Number patterns and divisibility

📝 Practice Quiz🧩 Puzzle Simulator

1. What is divisibility?

A whole number is divisible by another whole number when the division leaves remainder zero. Divisibility rules help us test this quickly without carrying out long division.

a is divisible by b ⇔ a ÷ b has remainder 0

2. Important divisibility rules

3Sum of digits is divisible by 3372 → 12
4Last two digits form a multiple of 41,316 → 16

3. Missing-digit puzzles

Use the divisibility rule to find which digit can replace the box.

Example: 5□2 is divisible by 3.
Digit sum = 5 + □ + 2 = 7 + □.
Possible digits: 2, 5 or 8.

Check every digit from 0 to 9. If the question asks for the smallest or greatest digit, compare all valid choices rather than stopping at the first one.

4. Divisibility by two numbers

To be divisible by both numbers, a number must satisfy both tests. For example, divisibility by 6 means divisibility by 2 and 3 together.

Divisible by 6 → even AND digit sum divisible by 3
Divisible by 12 → divisible by 3 AND by 4

5. Number patterns and multiples

Look for the amount added each time. A pattern such as 8, 16, 24, 32, … contains multiples of 8. To find its first term divisible by 9, find the least common multiple of 8 and 9.

LCM(8, 9) = 72
First common multiple = 72

For a pattern that starts at a different number, list its terms and test them in order.

6. A reliable puzzle-solving method

  1. Read the exact condition: divisible by one number or by several?
  2. Choose the matching divisibility rule.
  3. Test all possible missing digits or pattern terms.
  4. Check the final number by division or a second method.
  5. For “smallest” or “greatest”, compare all valid candidates.

Common mistakes

  • For divisibility by 4 or 8, checking only the last digit.
  • For divisibility by 6, checking evenness but forgetting divisibility by 3.
  • Assuming a missing digit has only one possible value without testing all digits.
  • Confusing a term number with the value of that term.

Quick revision

2 → last digit even
3 and 9 → digit sum
4 → last 2 digits
5 → last digit 0 or 5
6 → tests for 2 and 3
8 → last 3 digits
10 → last digit 0
