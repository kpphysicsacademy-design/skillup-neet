Equations with Variables on Both Sides

Learn to collect variable terms, move constants, isolate the unknown and check your answer without changing the balance of an equation.

ax + b = cx + d

1. What does “variables on both sides” mean?

The unknown variable appears in expressions on the left and right of the equals sign. The goal is to gather all variable terms on one side and all constants on the other.

Example: 2x + 3 = x + 11. Subtract x from both sides: x + 3 = 11. Then subtract 3: x = 8.

2. A reliable solving method

  1. Simplify each side first, including brackets and like terms.
  2. Subtract or add a variable term on both sides to collect variables on one side.
  3. Add or subtract constants on both sides to isolate the variable term.
  4. Divide by the coefficient of the variable.
  5. Substitute the result into the original equation to verify both sides.

3. Worked examples

Example A: 5x − 4 = 3x + 10
5x − 3x = 10 + 4
2x = 14
x = 7
Check: 5(7) − 4 = 31 and 3(7) + 10 = 31.
Example B: 4x + 6 = 2x + 18
4x − 2x = 18 − 6
2x = 12
x = 6.
Example C: 3(x + 2) = x + 14
3x + 6 = x + 14
2x = 8
x = 4.

4. Special cases

One solution
2x + 3 = x + 8 gives x = 5.
No solution
2x + 3 = 2x + 8 reduces to 3 = 8, which is false.
Infinitely many solutions
2x + 3 = 2x + 3 is true for every value of x.
Key idea
When variable terms cancel, compare the remaining constants.

5. Common mistakes

  • Moving a term without applying the same operation to both sides.
  • Changing a sign incorrectly when subtracting a negative term.
  • Forgetting to distribute a multiplier across every term in brackets.
  • Combining unlike terms, such as 3x and 4.
  • Checking only one side instead of evaluating both sides.

Quick revision

Simplify → collect variable terms → collect constants → divide by the coefficient → check in the original equation. If the variable terms cancel, determine whether the remaining statement is true or false.
