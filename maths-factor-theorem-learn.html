Factor Theorem

Brief Learn • Class 9 • Polynomials and Factorisation

📝 Practice Quiz🧪 Interactive Simulator

1. What is a factor?

A polynomial g(x) is a factor of p(x) when division leaves remainder zero. For a linear factor, we can test it without long division.

(x − a) is a factor of p(x) ⇔ p(a) = 0

This works in both directions. The value a is called a zero (root) of p(x).

2. Link to the Remainder Theorem

p(x) = (x − a)q(x) + p(a)

Dividing by x − a leaves remainder p(a). A zero remainder means exact division, so x − a is a factor.

3. Test a factor in three steps

  1. Set the proposed factor equal to zero to find the test value.
  2. Substitute that value into p(x).
  3. If the result is 0, it is a factor. Otherwise it is not.
p(x) = x² − 5x + 6; test x − 2
p(2) = 4 − 10 + 6 = 0
Therefore x − 2 is a factor.

4. Watch the sign

For x + 3, substitute x = −3, not +3. More generally, for 2x − 3, substitute x = 3/2.

p(x) = x² + 5x + 6
p(−3) = 9 − 15 + 6 = 0
Therefore x + 3 is a factor.

5. Find an unknown coefficient

If x − 2 is a factor of p(x) = x² + kx − 8, then p(2) = 0.

4 + 2k − 8 = 0 → 2k = 4 → k = 2

6. Factorise a polynomial

For p(x) = x³ − 6x² + 11x − 6, testing x = 1, 2, 3 gives zero each time. Thus:

p(x) = (x − 1)(x − 2)(x − 3)

After finding one factor, use division to reduce the degree and find remaining factors.

Quick revision

  • p(a) = 0 means x − a is a factor.
  • x + a requires testing p(−a).
  • p(a) ≠ 0 means the proposed factor does not divide exactly.
  • A zero of a polynomial is an x-value, not a factor expression.
