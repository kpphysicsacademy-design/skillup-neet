Generalising Number Properties

Use letters like n, a and b to describe rules that work for many numbers, not just one example.

🧩 Try Simulator✍️ Practise Quiz

1. What does generalising mean?

Generalising means finding a rule that works for many numbers. We use a letter to stand for any number.

n + 7
This means “a number increased by 7”. If n = 3, the answer is 10. If n = 20, the answer is 27.

Remember: “less than” reverses the order. Three less than x is x − 3.

3. Number properties

Even number: 2n
Odd number: 2n + 1
Two consecutive integers: n and n + 1
Two consecutive even numbers: 2n and 2n + 2

Here n is an integer. These forms describe every even or odd integer.

4. Four useful properties

Commutative: a + b = b + a (changing order does not change the sum).

Associative: (a + b) + c = a + (b + c) (changing grouping does not change the sum).

Distributive: a(b + c) = ab + ac.

Identity: a + 0 = a and a × 1 = a.

5. Expand and simplify

Example: 3(x + 4)
Multiply 3 by each term: 3 × x + 3 × 4
= 3x + 12
Example: 2(3x − 4) + 5(x + 1)
= 6x − 8 + 5x + 5
= 11x − 3

6. How to solve a generalisation question

  1. Identify what the letter represents.
  2. Translate the words into an expression.
  3. Use the correct property or expand brackets.
  4. Check your rule with a simple number.
