Graph of a Linear Equation

Brief Learn • Class 9 • Coordinate geometry and linear equations

📝 Practice Quiz📐 Simulate

1. What does the graph represent?

A linear equation in two variables can be written as ax + by + c = 0, where a and b are not both zero. Each solution is an ordered pair (x, y). Plotting all its solutions gives a straight line.

ax + by + c = 0

Every point on the line satisfies the equation, and every solution point lies on the line.

2. How to draw the graph

  1. Write the equation clearly.
  2. Choose a value for x and calculate y, or choose y and calculate x.
  3. Find at least two distinct solution pairs.
  4. Make a table of values and plot the ordered pairs on the Cartesian plane.
  5. Join the points with a straight line and extend it in both directions.
  6. Check a third solution, if available, to verify the line.
Example: 2x + 3y = 12. If x = 0, y = 4 → (0, 4). If y = 0, x = 6 → (6, 0). Plot both points and join them.

3. Intercepts make plotting easier

x-interceptSet y = 0. The line meets the x-axis at (x, 0).
y-interceptSet x = 0. The line meets the y-axis at (0, y).
For 3x + y = 9: y = 0 gives x = 3, so (3, 0). x = 0 gives y = 9, so (0, 9).

4. Read special straight lines

y = kHorizontal line, parallel to the x-axis.
x = hVertical line, parallel to the y-axis.
y = mxPasses through the origin (0, 0).
y = mx + dy-intercept is d; slope is m.

For Class 9 graphing, focus on ordered pairs, plotting, intercepts, and interpreting the line. Slope can help describe the direction and steepness.

5. Quick revision checklist

✓ A solution is an ordered pair (x, y). ✓ Two distinct points determine a straight line. ✓ Set y = 0 for the x-intercept. ✓ Set x = 0 for the y-intercept. ✓ Every point on the line satisfies the equation.
