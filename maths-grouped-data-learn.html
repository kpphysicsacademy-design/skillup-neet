Grouped Data

When a dataset contains many observations, we organize the values into class intervals and record how many observations fall in each class. This makes large datasets easier to read and compare.

Total frequency = Σf

1. Frequency

Frequency tells how many observations belong to a particular value or class. The total frequency is the sum of all class frequencies.

10–207

Total16

Example: 7 observations belong to the class 10–20. Total observations = 4 + 7 + 5 = 16.

2. Class interval and class limits

A class interval is a group or range used to organize observations. For the interval 10–19, the lower class limit is 10 and the upper class limit is 19.

3. Class width and class mark

Class width = upper boundary − lower boundary
Class mark = (lower limit + upper limit) ÷ 2

For the interval 10–20, the width is 10 and the class mark is (10 + 20) ÷ 2 = 15.

4. Read a grouped frequency table

Compare frequencies to identify the class with the greatest frequency. Add frequencies to find the total number of observations or the cumulative frequency up to a class.

The greatest frequency is 7 in the class 10–20. Cumulative frequency through the second class is 4 + 7 = 11.

5. Quick worked examples

  1. Class mark of 40–50: (40 + 50) ÷ 2 = 45.
  2. Total frequency of 4, 7, 6 and 3: 4 + 7 + 6 + 3 = 20.
  3. If total frequency is 21 and two frequencies are 5 and 8, the missing frequency is 21 − 5 − 8 = 8.
  4. For class mark 35 and width 10, the symmetric boundaries are 30 and 40.

6. Remember

  • Frequency is a count of observations.
  • Total frequency equals the sum of class frequencies.
  • Class mark is the midpoint of the interval limits.
  • Class width is the size of the interval.
  • Do not confuse a class limit with its class mark or frequency.
