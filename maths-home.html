📐 Mathematics: Zero → IIT Mastery

If you are starting from zero, do not jump into advanced problems. Build the foundation first, then progress toward JEE Main and JEE Advanced.

FOUNDATION FIRSTPROGRESSIVE LEARNINGJEE PATH

Level 0 — Maths Zero

Numbers, whole numbers, integers, signs, basic operations, fractions, powers and order of operations.

Start Number Basics Quiz

Level 1 — Arithmetic Foundation

Fractions, decimals, percentages, ratio, proportion, averages, powers, roots, exponents and surds.

Learn Level 1Level 1 Quiz Path

Level 2 — Algebra Foundation

Variables, expressions, identities, factorisation, linear equations, quadratic equations, polynomials and inequalities.

Level 3 — Core Mathematics

Sets, relations, functions, logarithms, sequences and series, complex numbers, permutations, combinations, binomial theorem and mathematical induction.

Level 4 — Geometry & Trigonometry

Angles, triangles, coordinate geometry, straight lines, circles, conics, trigonometric ratios, identities, equations and inverse trigonometry.

Level 5 — Calculus

Limits, continuity, differentiation, applications of derivatives, integration and differential equations.

Level 6 — JEE Main

Mixed chapter practice, timed problem solving, formula application and error correction.

Level 7 — JEE Advanced

Multi-concept problems, deeper reasoning, advanced algebra, geometry and calculus problem solving.

Study rule: Learn → Basic examples → Basic quiz → Practice → Review mistakes → Mixed test → Advanced problems.
