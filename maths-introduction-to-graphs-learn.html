CLASS 8 · DATA & GRAPHS

Introduction to Graphs

Learn how to read information, choose a suitable scale, plot points and understand simple graphs.

🧮 Try Simulator✍️ Start Quiz

1. What is a graph?

A graph is a visual way to present information. It helps us compare quantities, notice patterns and understand how two quantities change.

Bar graph

Compares separate categories using bars.

Line graph

Shows how a quantity changes, often over time.

2. Cartesian coordinate plane

Two number lines meet at right angles. The horizontal number line is the x-axis and the vertical number line is the y-axis. Their meeting point is the origin.

Ordered pair = (x, y)

Move horizontally first to x, then vertically to y. For example, (3, 2) means 3 units right and 2 units up.

Remember the signs
Right: positive x · Left: negative x
Up: positive y · Down: negative y

3. The four quadrants

Quadrant I
(+, +)
Quadrant II
(−, +)
Quadrant III
(−, −)
Quadrant IV
(+, −)

Points on either axis are not inside a quadrant. The origin is (0, 0).

4. Plotting a point

Plot (−2, 3)
① Start at the origin (0, 0).
② Move 2 units left to x = −2.
③ Move 3 units up to y = 3.
④ Mark the point and label it (−2, 3).

5. Choose a suitable scale

A scale tells how much each division represents. If one division represents 5 units, the marks can be 0, 5, 10, 15, and so on. Use equal intervals and label the axes with quantities and units.

Equal spacing = equal value steps

6. Read a line graph

Read the horizontal axis for the input or time and the vertical axis for the measured value. Check the scale before comparing points. A rising line indicates an increase; a falling line indicates a decrease.

Quick check

Which coordinate is written first in (4, −2)?
