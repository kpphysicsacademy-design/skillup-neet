Laws of Exponents

Use these rules to simplify powers with the same base.

1. Multiply powers

Keep the base; add exponents.

aᵐ × aⁿ = aᵐ⁺ⁿ

2. Divide powers

Keep the base; subtract exponents. a ≠ 0.

aᵐ ÷ aⁿ = aᵐ⁻ⁿ

3. Power of a power

Multiply the exponents.

(aᵐ)ⁿ = aᵐⁿ

4. Power of a product

Apply the exponent to each factor.

(ab)ⁿ = aⁿbⁿ

5. Zero exponent

Any non-zero base raised to zero is one.

a⁰ = 1, a ≠ 0

6. Negative exponent

Take the reciprocal.

a⁻ⁿ = 1/aⁿ, a ≠ 0
Rational exponents
aᵐ/ⁿ = ⁿ√(aᵐ), where the root is defined. Example: 16³/⁴ = (⁴√16)³ = 2³ = 8.
Remember
For division and negative exponents, the base cannot be zero. Follow the order: simplify powers first, then calculate.
