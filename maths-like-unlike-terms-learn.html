Like and Unlike Terms

Learn how to compare algebraic terms by examining their variable parts and exponents.

1. What are like terms?

Terms are like terms when they have exactly the same variables raised to the same powers. Their coefficients may be different.

4x, −7x, ½x → Like terms

Each term has the same variable part, x.

2. Unlike terms

Terms are unlike when their variable parts differ in a variable or in its exponent.

3x and 3x² → Unlike
5ab and 5a → Unlike

Having the same coefficient does not make terms like.

3. Order of variables does not matter

6xy and −2yx → Like terms

Multiplication is commutative, so xy and yx represent the same variable part.

4. Constants

All constant terms are like terms because none contains a variable.

8, −3, 0.25 → Like terms

5. Combine like terms

Add or subtract the numerical coefficients and keep the common variable part unchanged.

7x + 3x − 2x = (7 + 3 − 2)x = 8x
4a + 2b − a + 5b = 3a + 7b

Unlike terms remain separate; for example, 2x + 3x² cannot be combined into one term.

Quick checklist

✓ Compare every variable. ✓ Compare each exponent. ✓ Ignore coefficient and sign when deciding whether terms are like. ✓ Combine only matching variable parts.
