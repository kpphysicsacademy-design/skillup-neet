Like & Unlike Terms

One simple rule: compare the variables and their powers.

The rule

Same variables + same powers = Like terms

The number in front (coefficient) and its sign can be different.

Examples

4x, −7xLike terms: same x
3x, 3x²Unlike: powers differ
5xy, −2yxLike: xy = yx
5ab, 5aUnlike: variables differ

How to combine

Add or subtract coefficients. Keep the common variable part.

7x + 3x − 2x = 8x

Unlike terms stay separate: 2x + 3x² cannot be combined.

Remember

1Check that every variable matches.
2Check that each variable has the same exponent.
3Ignore coefficient and sign when grouping like terms.
