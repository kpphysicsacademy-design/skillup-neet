CLASS 8 · NUMBER SENSE

Number Patterns

Learn to spot the rule, continue a sequence and find a missing number—one simple step at a time.

🧮 Try Simulator✍️ Start 30-question Quiz

1. What is a number pattern?

A number pattern is a list of numbers arranged by a rule. Find how one term changes into the next.

Example
4, 7, 10, 13, 16, …
Each new term is 3 more than the previous one. The next term is 19.

2. Common pattern rules

➕ Add a fixed number

2, 5, 8, 11, … Add 3.

➖ Subtract a fixed number

20, 16, 12, 8, … Subtract 4.

✖️ Multiply

3, 6, 12, 24, … Multiply by 2.

➗ Divide

81, 27, 9, 3, … Divide by 3.

3. Look at the differences

Subtract each term from the term after it. Equal differences usually show an arithmetic pattern.

3, 8, 13, 18, 23

Differences: +5, +5, +5, +5. So the next term is 28.

4. Special number patterns

Square numbers
1, 4, 9, 16, 25, … (1², 2², 3², 4², 5²)

Cube numbers
1, 8, 27, 64, 125, …

Fibonacci-style pattern
1, 1, 2, 3, 5, 8, 13, … Add the previous two terms.

5. Find a missing term

  1. Compare neighbouring terms.
  2. Check addition, subtraction, multiplication or division.
  3. Write the rule clearly.
  4. Test the rule on every term before filling the blank.
6, 10, □, 18, 22

The rule is +4, so the missing term is 14.

6. Find the nth term

For a simple arithmetic sequence, use the first term and common difference.

nth term = a + (n − 1)d

Here, a is the first term and d is the common difference.

For 4, 7, 10, 13, … : a = 4 and d = 3.
nth term = 4 + (n − 1) × 3 = 3n + 1.

Quick check

What comes next: 6, 11, 16, 21, …?
