Polygons and Angle Sums

Understand polygon names, interior and exterior angles, regular polygons and diagonals. Learn the relationships, then practise applying them.

Interior-angle sum = (n − 2) × 180°

1. What is a polygon?

A polygon is a closed plane figure made from a finite number of straight line segments. The segments meet only at their endpoints. The number of sides determines its name.

2. Interior angle sum

A polygon with n sides can be divided into (n − 2) triangles by drawing diagonals from one vertex. Each triangle has an angle sum of 180°.

S = (n − 2) × 180°
Example: Pentagon
n = 5
S = (5 − 2) × 180°
S = 3 × 180° = 540°.

3. Regular polygons

A regular polygon has all sides equal and all interior angles equal. Divide the total angle sum by the number of sides to find each interior angle.

Each interior angle = ((n − 2) × 180°) / n
Example: Regular hexagon
Total = (6 − 2) × 180° = 720°
Each interior angle = 720° ÷ 6 = 120°.

4. Exterior angles

An exterior angle is formed by extending one side of a polygon. An interior angle and its adjacent exterior angle form a straight angle.

Interior angle + adjacent exterior angle = 180°

For any convex polygon, one exterior angle at each vertex, taken in the same direction, adds up to one full turn.

Exterior-angle sum = 360°
Example: Regular decagon
Each exterior angle = 360° ÷ 10 = 36°.
Each interior angle = 180° − 36° = 144°.

5. Find the number of sides

From interior-angle sum
S = (n − 2) × 180°
Divide S by 180°, then add 2.
Example: S = 1,080° gives n = 1,080 ÷ 180 + 2 = 8 sides.
From each exterior angle of a regular polygon
n = 360° ÷ each exterior angle.
Example: 45° gives n = 360° ÷ 45° = 8 sides.

6. Diagonals

A diagonal joins two non-adjacent vertices of a polygon. From each vertex, diagonals can be drawn to n − 3 other vertices. Each diagonal is counted twice in this total.

Number of diagonals = n(n − 3) / 2
Example: Octagon
8(8 − 3) ÷ 2 = 8 × 5 ÷ 2 = 20 diagonals.

7. Common mistakes

  • Use (n − 2) × 180° for the interior-angle sum, not n × 180°.
  • Divide the total by n only when finding each angle of a regular polygon.
  • The exterior-angle sum of a convex polygon is 360°.
  • Adjacent interior and exterior angles add to 180°.
  • For diagonals, remember to divide n(n − 3) by 2.

Quick revision

Know the polygon name from its sides. Use the interior-sum formula for total angles, divide by n for each regular interior angle, use 360° for the exterior-angle sum, and apply n(n − 3)/2 for diagonals.
