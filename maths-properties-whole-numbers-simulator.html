Properties of Whole Numbers

Change the numbers, test an operation and observe which properties hold. All activities run on this page—no sign-in needed.

1. Property testing lab

Choose an operation and enter two whole numbers. Compare A ○ B with B ○ A, then inspect closure and identity.

Choose values and tap Test properties.

2. Commutative property

Does changing the order of the numbers keep the answer the same?

7 + 4 = 4 + 7
Addition and multiplication are commutative. Subtraction and division are not.

3. Associative property

Change the brackets to see whether grouping changes the result.

For whole numbers, addition and multiplication are associative.

4. Distributive property visualiser

Multiplication distributes over addition: A × (B + C) = (A × B) + (A × C).

5 × (10 + 2) = (5 × 10) + (5 × 2)
60 = 50 + 10 = 60

5. Identity and zero properties

Try any whole number and see what happens when you add zero or multiply by one and zero.

24 + 0 = 24 · 24 × 1 = 24 · 24 × 0 = 0

6. Remember the properties

Closure

Addition and multiplication of whole numbers always give a whole number.

Commutative

A + B = B + A and A × B = B × A. Not true for subtraction or division.

Associative

(A + B) + C = A + (B + C); the same holds for multiplication.

Distributive

A × (B + C) = A × B + A × C.

Additive identity

Adding 0 to a whole number leaves it unchanged.

Multiplicative identity

Multiplying a whole number by 1 leaves it unchanged.

Zero property

Any whole number multiplied by 0 gives 0.

Subtraction / division

These operations are not closed for all pairs of whole numbers.
