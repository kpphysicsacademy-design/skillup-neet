CLASS 8 · DATA HANDLING

Reading Line Graphs

Learn to read values, follow trends, compare changes and interpret information shown over time.

🧮 Try Simulator✍️ Start Quiz

1. What does a line graph show?

A line graph displays how a measured quantity changes across ordered categories or time. The plotted points are joined by line segments so patterns and trends are easy to see.

Horizontal axis (x)

Often shows time or the ordered categories.

Vertical axis (y)

Shows the measured quantity and its values.

2. Read the scale carefully

Check the numbers printed beside the vertical axis. Each large or small interval may represent more than one unit.

Example
If each grid interval represents 5 units, then 3 intervals above zero represent 3 × 5 = 15 units.
Value = number of intervals × value per interval

3. Understand line movements

Rising line ↗

The measured value increases.

Falling line ↘

The measured value decreases.

Flat line →

The measured value stays unchanged.

Steeper line

A greater change over the same horizontal interval.

4. Calculate a change

Example: water in a tank
At 8 AM = 40 L
At 10 AM = 20 L
Decrease = 40 − 20 = 20 L

For an overall change, subtract the starting value from the ending value. State whether the result is an increase or a decrease.

5. Compare rates over equal intervals

For equal time intervals, compare how much the measured value changes in each interval. A larger change means a greater average rate during that interval.

Average change per interval = total change ÷ number of intervals

6. Read a distance–time graph

On a distance–time graph, a rising line means distance from the starting point is increasing. A horizontal segment means distance is unchanged during that time interval, so the object is stationary.

Quick check

A line graph changes from 12 to 17. What is the increase?
