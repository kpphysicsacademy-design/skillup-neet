📏 Real Number Line

Every real number has one exact position on the number line.

1. Read the line

0 is the origin. Positive numbers are to the right; negative numbers are to the left. Equal gaps represent equal units.

Left = smaller · Right = greater

2. Plot rational numbers

Divide the unit interval into equal parts using the denominator. Count the numerator's parts from zero: right for positive, left for negative.

3/4 → 3 of 4 equal parts to the right

3. Locate irrational numbers

Use a right triangle and Pythagoras to construct the required length, then transfer it to the line. For √2, use two perpendicular sides of 1 unit.

√2 = √(1² + 1²) ≈ 1.414

4. Compare and measure

Numbers farther right are greater. Distance is always non-negative.

Distance = |a − b|
Midpoint = (a + b) / 2

⚡ Remember

Each real number matches exactly one point, and each point matches exactly one real number. Rational and irrational numbers together fill the real number line.
