Solutions of Equations

A solution is a value—or an ordered pair—that makes an equation true when substituted. Learn how to test values and find more solutions.

ax + by + c = 0

For a linear equation in two variables, a and b are not both zero. A solution is written as an ordered pair (x, y).

1. What does “solution” mean?

A solution is a value of the variable, or a pair of values, that satisfies the equation. Substitute the values and check whether the left-hand side equals the right-hand side.

Example: For x + y = 7, the pair (3, 4) is a solution because 3 + 4 = 7. The pair (2, 4) is not a solution because 2 + 4 ≠ 7.

2. How to find solutions

  1. Choose a value for x.
  2. Substitute it into the equation.
  3. Solve the resulting equation to find y.
  4. Write the answer in the order (x, y).
  5. Substitute both values again to verify.
Example: Find a solution of 2x + y = 8 when x = 3.
2(3) + y = 8 → y = 2.
Solution: (3, 2), since 6 + 2 = 8.

3. Infinitely many solutions

A linear equation in two variables generally has infinitely many real ordered-pair solutions. Each valid pair is one point on its straight-line graph.

x + y = 5
(0,5), (1,4), (2,3)
2x − y = 4
(0,−4), (2,0), (3,2)

4. Special cases

x = 3
All pairs whose first coordinate is 3. Its graph is vertical.
y = −2
All pairs whose second coordinate is −2. Its graph is horizontal.

5. Common mistakes

  • Writing (y, x) instead of (x, y).
  • Checking only one side instead of comparing both sides.
  • Assuming a single equation in two variables has only one solution.
  • Making an arithmetic or sign error during substitution.

Quick revision

A solution makes the equation true. Ordered pairs are written (x, y). Choose one variable, calculate the other, and verify by substitution. All solutions of a linear equation lie on its straight-line graph.
