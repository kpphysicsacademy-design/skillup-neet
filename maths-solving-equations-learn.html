Solving Equations

Learn how to find the unknown value by keeping both sides of an equation balanced. Use inverse operations, simplify carefully, and verify your answer.

Left-hand side = Right-hand side

1. What is an equation?

An equation is a mathematical statement that says two expressions are equal. A solution is a value of the variable that makes the statement true.

Example: In x + 5 = 12, the value x = 7 is a solution because 7 + 5 = 12.

2. Keep the equation balanced

Perform the same operation on both sides. This preserves equality while helping isolate the variable.

  1. Simplify each side if needed.
  2. Move variable terms to one side using addition or subtraction.
  3. Move constant terms to the other side.
  4. Divide or multiply to make the coefficient of the variable equal to 1.
  5. Substitute the answer into the original equation to check it.

3. Inverse operations

Addition ↔ Subtraction
If x + 6 = 14, subtract 6 from both sides.
Multiplication ↔ Division
If 4x = 20, divide both sides by 4.
Division ↔ Multiplication
If x/3 = 5, multiply both sides by 3.
Brackets
Use the distributive property before collecting like terms.

4. Worked examples

Example A: 2x + 3 = 13
2x = 13 − 3 = 10
x = 10 ÷ 2 = 5
Check: 2(5) + 3 = 13.
Example B: 5x − 4 = 2x + 8
5x − 2x = 8 + 4
3x = 12
x = 4
Check: 5(4) − 4 = 2(4) + 8 = 16.
Example C: 3(x + 2) = 18
3x + 6 = 18
3x = 12
x = 4.

5. Common mistakes

  • Changing a term's sign without performing the same operation on both sides.
  • Forgetting to multiply every term inside brackets.
  • Combining unlike terms.
  • Dividing only one term instead of the entire side when required.
  • Not checking the final value in the original equation.

Quick revision

An equation stays balanced when the same operation is applied to both sides. Use inverse operations to isolate the variable, simplify accurately, and verify by substitution.
