Read the five-number sequence around your selected number. Values never go below zero.

Consecutive whole numbers differ by exactly one.

Remember

• Successor = number + 1

• Predecessor = number − 1, when the number is greater than zero

• Zero is the smallest whole number, so it has no whole-number predecessor.
