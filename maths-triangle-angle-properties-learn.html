Triangle Angle Properties

Brief Learn · Class 9 · Master the rules before practice

1. Interior angle-sum property

The three interior angles of every triangle add up to 180°. This is true for acute, right and obtuse triangles.

∠A + ∠B + ∠C = 180°

Example: if ∠A = 48° and ∠B = 67°, then ∠C = 180° − 48° − 67° = 65°.

2. Exterior-angle property

An exterior angle of a triangle equals the sum of the two interior opposite (remote) angles.

Exterior angle = remote interior angle 1 + remote interior angle 2

Example: if the remote interior angles are 52° and 61°, the exterior angle is 113°.

The exterior angle and its adjacent interior angle form a linear pair, so their sum is 180°.

3. Isosceles triangle property

If two sides of a triangle are equal, the angles opposite those sides are equal. These are called the base angles.

AB = AC ⇒ ∠B = ∠C

If the vertex angle is 40°, each base angle is (180° − 40°) ÷ 2 = 70°.

4. Equilateral triangle

All three sides are equal. Therefore all three angles are equal, and each angle measures 60°.

∠A = ∠B = ∠C = 60°

5. Right triangle

One angle is 90°. The other two acute angles must add up to 90°.

Acute angle 1 + acute angle 2 = 90°

If one acute angle is 34°, the other is 56°.

6. Algebraic angle problems

Translate the given angle expressions into an equation, then use the 180° total.

(2x + 10) + (3x − 5) + (x + 25) = 180°

Combine like terms: 6x + 30 = 180, so x = 25°. Substitute back to obtain 60°, 70° and 50°.

Always check the final angles: each must be positive and their sum must be exactly 180°.

Fast exam checklist

  • Missing interior angle → subtract known angles from 180°.
  • Exterior angle → add the two remote interior angles.
  • Adjacent interior and exterior angles → add to 180°.
  • Isosceles triangle → base angles are equal.
  • Right triangle → acute angles add to 90°.
  • Algebraic angles → form one equation using the angle sum.
