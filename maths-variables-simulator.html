Variables Simulator

An interactive algebra workspace. Explore variables, substitute values, translate words into expressions and generate input–output tables with MathJax-rendered notation.

How to use this simulator

Select a lab, enter values and calculate. Mathematical expressions are displayed in clear textbook-style notation.

\\[ ax+b,\\quad x^2,\\quad \\frac{x}{n} \\]

Substitution lab

Enter an expression and a value for x. Use numbers, x, +, −, ×, ÷, brackets and powers (for example: 2*x^2+3).

\\[2\\times 4^2+3\\]
Result = 35

Words to algebra

Choose a phrase and see how it is represented using a variable.

\\[x+7\\]
A number increased by 7 is written as x + 7.

Input–output machine

Choose a rule, enter inputs and observe the outputs.

\\[y=2x+3\\]
