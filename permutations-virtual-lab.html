Virtual Lab: Permutations

Change n (available distinct objects) and r (positions filled) to see why order matters in a permutation.

1. Set up an arrangement

Objects are distinct and are not reused.

2. Observe the result

nP r = n! / (n − r)!
5P3 = 60
5 × 4 × 3 = 60

There are 60 ordered arrangements.

For distinct objects, swapping positions generally creates a different permutation.

3. Permutation or combination?

Permutation: the order/roles matter (president, secretary, treasurer).

Combination: only the chosen group matters (selecting a committee).

nC r = n! / (r!(n − r)!)

For the same n and r, combinations count groups without treating rearrangements as new selections.

Learning checklist

  • Check whether order matters.
  • Check whether repetition is allowed.
  • For distinct objects without repetition, multiply descending choices.
  • Use factorial notation to express the product compactly.
