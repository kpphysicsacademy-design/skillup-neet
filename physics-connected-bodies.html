Connected Bodies

Two or more objects joined by a string move together. Use Newton’s second law, ΣF = ma, to find their acceleration and tension.

TensionAccelerationPulley

1. Remember these rules

  • A taut, inextensible string connects the motion of the bodies.
  • For an ideal string and smooth pulley, tension is the same throughout.
  • For a fixed pulley, connected bodies have equal acceleration magnitudes.
  • Tension always pulls; it never pushes.

2. Atwood machine

Two masses hang on opposite sides of a pulley. The heavier mass moves down.

a = |m₂ − m₁|g / (m₁ + m₂)
T = 2m₁m₂g / (m₁ + m₂)
Example: m₁ = 4 kg, m₂ = 6 kg, g = 10 m/s².
a = (6 − 4) × 10 / 10 = 2 m/s²
T = 4(10 + 2) = 48 N

3. Block on table + hanging mass

A block m on a smooth table is connected to a hanging mass M.

a = Mg / (m + M)
T = ma
Example: m = 4 kg, M = 1 kg, g = 10 m/s².
a = 10 / 5 = 2 m/s²; T = 4 × 2 = 8 N

4. Two blocks pulled together

If force F pulls two connected blocks on a smooth surface, first treat them as one system.

a = F / (m₁ + m₂)

To find tension, apply ΣF = ma to either block separately.

Quick solving steps

  1. Draw a free-body diagram for each object.
  2. Choose the direction of motion as positive.
  3. Write ΣF = ma for each object.
  4. Use the string constraint: equal acceleration magnitudes.
  5. Solve for acceleration and tension.
Key idea: First find the acceleration of the complete system. Then isolate one block to find tension.
