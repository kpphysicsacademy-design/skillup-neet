1. Meaning of measurement error

Measurement error is the difference between an observed reading and a true or accepted reference value. No real measurement is perfectly exact; a result should be interpreted with its uncertainty.

Absolute error = |measured value − accepted value|

2. Accuracy, precision and uncertainty

Accuracy describes closeness to the accepted value. Precision describes the closeness of repeated readings to one another. Uncertainty expresses the range within which the measured value is reasonably expected to lie.

A set of readings can be precise but inaccurate if a systematic error shifts them all.

3. Absolute error

Absolute error is the magnitude of the difference between a measured value and its reference value. It has the same unit as the measured quantity.

If L = 9.8 cm and L₀ = 10.0 cm, then ΔL = |9.8 − 10.0| = 0.2 cm

4. Relative and percentage error

Relative error compares the absolute error with the magnitude of the reference value. Percentage error is the relative error expressed as a percentage.

Relative error = absolute error / |reference value|
Percentage error = relative error × 100%

5. Random errors

Random errors vary unpredictably from one reading to another because of small changes in conditions, observer judgement or instrument fluctuations. Repeated readings and a suitable average help reduce their effect.

  • Take several independent readings.
  • Use the mean when appropriate.
  • Do not assume averaging removes systematic error.

6. Systematic errors

Systematic errors shift readings consistently in one direction or by a repeatable amount. Common causes include poor calibration, zero error, incorrect method and environmental influence.

Systematic errors are not reliably removed by simply taking more readings. Identify and correct the cause.

7. Instrumental and observational errors

  • Zero error: the instrument shows a non-zero reading when the input is zero.
  • Least count/resolution: the smallest scale change that can be read.
  • Parallax: viewing a scale from an angle instead of at eye level.
  • Calibration error: instrument response differs from its reference.

8. Reporting and reducing measurement errors

Record the measured value with its unit and, where appropriate, its uncertainty. Use calibrated instruments, read scales at eye level, repeat measurements and retain sensible precision.

Example: (5.0 ± 0.1) cm

The ± value communicates the stated uncertainty; it is not a guarantee that the true value must lie within that interval.
