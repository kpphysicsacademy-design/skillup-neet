Tension force

Tension is the pulling force transmitted through a taut string, rope or cable. It acts along the string and pulls an attached object away from the point of contact.

Tension acts along a taut string

1. Hanging object at rest or constant velocity

When a mass hangs vertically with zero acceleration, tension balances its weight.

T = mg

Example: a 2 kg mass at rest with g = 10 m/s² has T = 2 × 10 = 20 N.

2. Vertical acceleration

For an object accelerating upward, tension must exceed weight. For downward acceleration, tension is smaller than weight.

Upward: T = m(g + a)
Downward: T = m(g − a)

In free fall, a = g and the string becomes slack, so T = 0.

3. Horizontal motion

For a block on a frictionless horizontal surface pulled by a horizontal string, tension provides the net horizontal force.

T = ma

4. Ideal pulley systems

  • For a massless string over a frictionless pulley, tension is uniform throughout the string.
  • For an Atwood machine: a = (m₂ − m₁)g / (m₁ + m₂), where m₂ is the heavier mass.
  • For a table block m₁ connected to a hanging mass m₂: a = m₂g / (m₁ + m₂).

Remember

A string can pull but cannot push. Tension acts along the string, not necessarily vertically. Always draw a free-body diagram and apply Newton’s second law to each object.

Worked example

A 3 kg object is lifted vertically upward with acceleration 2 m/s². Take g = 10 m/s².

T = m(g + a) = 3(10 + 2) = 36 N

Exam tip: choose a positive direction first, then apply ΣF = ma along the string or direction of motion.
