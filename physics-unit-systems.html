1. What is a system of units?

A system of units is an agreed collection of units used to measure physical quantities. A good system is coherent, consistent and internationally understood.

Physical quantity = numerical value × unit

2. CGS system

CGS uses centimetre, gram and second as its fundamental units of length, mass and time.

  • Length: centimetre (cm)
  • Mass: gram (g)
  • Time: second (s)
  • Force: dyne; energy: erg

3. FPS system

FPS uses foot, pound and second as its fundamental units. Distinguish pound-mass from pound-force in mechanics problems.

  • Length: foot (ft)
  • Mass: pound (lb) in the mass-based form
  • Time: second (s)

4. MKS system

MKS is based on metre, kilogram and second. It provides the mechanical foundation from which the modern SI system developed.

  • Length: metre (m)
  • Mass: kilogram (kg)
  • Time: second (s)
  • Force: newton (N); energy: joule (J)

5. International System (SI)

SI is the internationally accepted system. It defines seven base quantities and their units: metre, kilogram, second, ampere, kelvin, mole and candela.

SI is a modern, coherent system based on fixed values of defining physical constants.

6. Fundamental and derived units

Base units are defined independently. Derived units are formed by multiplying or dividing powers of base units.

  • Velocity: m s⁻¹
  • Acceleration: m s⁻²
  • Force: kg m s⁻² = N
  • Pressure: kg m⁻¹ s⁻² = Pa

7. Comparing CGS and SI

  • 1 m = 100 cm
  • 1 kg = 1000 g
  • 1 newton = 10⁵ dynes
  • 1 joule = 10⁷ ergs

Use conversion factors carefully when changing a numerical value from one system to another.

8. Coherent units and choosing a system

A coherent system produces derived units without extra numerical conversion factors. SI is preferred in science because it is globally standardized and coherent.

Remember: CGS = cm–g–s, MKS = m–kg–s, FPS = ft–lb–s.
